# Grill Assistant

A Home Assistant integration that keeps the cook of each meat probe on a grill: cook type, doneness, target, progress, rate, done time, done and stalled. Every browser shows the same cook at once, a change made in one shows in all, and automations can use it. It needs no helpers and no automations.

It works with any temperature sensor. ThermoWorks RFX probes on the ThermoWorks Cloud integration need no setup: their reading (channel 0) is suggested, and their four sensors are found in order.

The [Grill Card](https://github.com/GizmoGoody/grill-card) shows it on a dashboard.

> [!WARNING]
> **Alpha developmental software. Use with caution.** Do not rely on it alone for food safety. Check the temperature with a second thermometer before serving.
